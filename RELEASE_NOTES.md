## Star3D 0.6.0 Beta

### What's new

**World Builder**
- World Builder is part of the engine: open it from the build icon in the editor's top bar. Build a world with land, trees, houses, water and effects, and give its elements colliders (box, sphere, capsule or mesh).
- New 3D element "World": choose a world and it is shown in your scene as it is, with its ground and colliders for physics. Edit, Choose and New sit at the top of its properties; Edit opens World Builder and the scene shows the changes when you come back. Worlds are saved in the project's worlds folder and go into exported games.

**Shaders**
- Shader library: a button beside the Shader property of 3D elements opens 57 ready shaders from World Builder (Shatter, Evaporate, Glass and hologram, Fantasy), each with a picture and a description, with search. Choosing one copies it into the project's shaders folder, so it works in exported games and you can edit it. Tune it with Shader Params: amount, speed, tint.

**Editor**
- The block list draws each block with its real shape, and dragging a block shows it under your finger.
- UI holder: Edit, New and the chosen UI are at the top of its properties.

**Home screen**
- The World Builder tile is replaced by "Support": community links (now including Telegram) and ways to support the engine.
- Community links use the icons of each platform.

### العربية
- **World Builder داخل المحرر:** أيقونة البناء في الشريط العلوي تفتحه. ابنِ عالماً بأرض وأشجار وبيوت وماء ومؤثرات، وأضف للعناصر كولايدر (صندوق، كرة، كبسولة، شبكة).
- **عنصر 3D جديد "عالم":** اختر عالماً فيظهر في المشهد كما هو، مع أرضه وكولايدراته للفيزياء. أزرار تعديل واختيار وجديد أعلى الخصائص، وتظهر التعديلات عند رجوعك من World Builder. العوالم تُحفظ في مجلد worlds بالمشروع وتدخل في الألعاب المصدّرة.
- **مكتبة شيدرات:** زر بجانب خاصية Shader يفتح 57 شيدر جاهز من World Builder (تحطّم، تبخّر، زجاج وهولوغرام، خيال وسحر) بصورة ووصف لكل واحد وبحث. الاختيار ينسخ الشيدر إلى مجلد shaders بالمشروع فيعمل في الألعاب المصدّرة ويمكن تعديله.
- قائمة البلوكات تعرض كل بلوك بشكله الحقيقي، والسحب يُظهره تحت إصبعك.
- UI Holder: أزرار تعديل وجديد والواجهة المختارة أعلى الخصائص.
- في الرئيسية صار "الدعم" بدل World Builder: روابط المجتمع (ومعها تلجرام) وطرق دعم المحرك، بأيقونات المنصات.

## Star2D 0.5.7 Beta

### What's new

**Najma (نجمة): code your game in Arabic**
- A new way to write scripts: plain Arabic sentences such as "حرك نفسي يميناً بسرعة ٢٠٠" (move me right at speed 200). Easy to start with, complete enough for experienced developers.
- When you create an element script or a scene script you choose: Najma (Arabic) or Java. Both can live in the same project.
- Its own editor made for Arabic: colors, mistakes explained in Arabic as you type, and smart suggestions that know what comes next.
- A full guide inside the editor (the "؟" button): from "Hello world" to advanced topics, with more than 20 ready examples you can copy (player movement, coins, enemies, shooting, timers, saving the best score...).
- Games run exactly as fast as before and are not bigger.

**Path finding**
- New element "Path grid" (NAVGRID) in Add > Game systems, for 2D and 3D scenes: square or hexagon cells.
- Paint walls and slow ground (mud, water) on the canvas, or make walls from the static elements in one tap. Obstacles (doors, crates) are followed when they move and open their cells when they are destroyed.
- "Smart Chase" behaviors (2D and 3D): enemies run after the player along the shortest way, find a new way when a door closes, or run away.
- New variable type PathHolder: draw patrol paths on the canvas, or fill them with "Find path".
- 21 Navigation blocks (walk to, chase, flee, follow path, obstacles, cells...) and path events.

**Timeline**
- Timeline panel: keyframe animations of position, rotation, size, color, opacity, image, text and variables, for 2D and 3D elements.
- Record mode: move the playhead and change the element, keys are added by themselves. 10 transitions with a preview, markers, loop / ping-pong, relative timelines, play on another element (@self).
- Timeline blocks and quick Tween blocks (with delay, repeat and back-and-forth).

**Local multiplayer (Wi-Fi / hotspot)**
- New element "Network play" (NETWORK): rooms, max players, player template copied for each player, ready-made lobby.
- "Network" card on every element: the same on every phone, moved by the host or by a player.
- Network blocks: host, search, join, start for everybody, messages, spawn, ownership, and 20 value blocks; network events.

**Examples**
- Maze Chase: tap to walk, smart ghosts, a guard on a patrol path, a key that opens a door, and a hexagon maze.
- Wi-Fi Stars: lobby + arena, each phone moves its own ball, the host spawns the stars and counts the points.

### العربية
- **لغة نجمة، اكتب كود لعبتك بالعربية:** جمل عربية بسيطة مثل «حرك نفسي يميناً بسرعة ٢٠٠»، سهلة للمبتدئين وكاملة للمحترفين. عند إنشاء سكربت لعنصر أو مشهد تختار: نجمة (عربي) أو Java. لها محرر خاص بالعربية بألوان واقتراحات ذكية وأخطاء مشروحة بالعربية، وشرح كامل داخل المحرر (زر «؟») من «مرحباً بالعالم» حتى الاحتراف مع أكثر من ٢٠ مثالاً جاهزاً للنسخ. والألعاب تعمل بنفس السرعة والحجم.
- **إيجاد المسار:** عنصر شبكة المسارات (مربعة أو سداسية) لـ 2D و 3D، رسم الجدران والأرض البطيئة، عوائق متحركة، سلوك المطاردة الذكية، نوع متغير PathHolder لمسارات الدوريات، و21 بلوك ملاحة.
- **الخط الزمني:** تحريك بالإطارات المفتاحية مع وضع التسجيل، 10 انتقالات، علامات، تكرار وذهاب وإياب، وبلوكات Tween.
- **اللعب الجماعي عبر الواي فاي:** عنصر الشبكة، صالة انتظار جاهزة، بطاقة الشبكة لكل عنصر، وبلوكات وأحداث الشبكة.
- **أمثلة جديدة:** Maze Chase و Wi-Fi Stars.
