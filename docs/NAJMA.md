# نجمة (Najma): لغة البرمجة العربية في Star2D

نجمة لغة عربية تُكتب بها سكربتات اللعبة. المحرر يحوّل ملف `.njm` إلى ملف `.java` قبل البناء، فلا يدخل في اللعبة أي مفسّر:
لا زيادة في الحجم ولا فرق في الأداء عن Java. الملف الوحيد الذي يضاف للمشروع هو `java/najma/N.java` (دوال مساعدة صغيرة).

Transpiler: `.njm` → `.java` (same line numbers) → ecj / javac → dex

## أين تُكتب

| النوع | المسار | الناتج |
|---|---|---|
| سكربت عنصر | `java/com/star4droid/Game/Scripts/<scene>/<Script>Script.njm` | صنف يرث `ItemRefs` الخاص بالمشهد |
| سكربت مشهد | `java/com/star4droid/Game/SceneScript/<scene>Script.njm` | صنف يرث `SceneRefs` |
| أي صنف آخر | `java/<package>/<Name>.njm` | صنف عادي |

عند إنشاء سكربت جديد لعنصر أو مشهد يسأل المحرر: «نجمة (عربي)» أم «Java». ملف `X.java` بجانب `X.njm` مولَّد (يبدأ بـ `/*najma*/`):
لا تعدّله، وفتحه يفتح محرر نجمة. إعادة تسمية العنصر تنقل ملف `.njm` معه عند البناء التالي.

## القواعد باختصار

كل أمر في سطر (أو يفصل بينها `؛`)، والكتل بين `{ }`، والتعليق يبدأ بـ `#`. الأرقام العربية والإنجليزية مقبولة، والتشكيل والهمزات
و«ال» التعريف لا تفرّق بين الأسماء (`اللاعب` = `لاعب`).

```
متغير النقاط = ٠                  # النوع يُستنتج. ٢٫٥ عشري. «خاصية» تظهر في Properties. «ثابت» لا يتغير
رقم_صحيح ع = ٥      رقم_عشري س = ١٫٥      نص الاسم = "علي"      منطقي حي = صح
قائمة من نص الأسماء = ["علي"، "سارة"]      قاموس من نص إلى رقم_صحيح الأسعار = جديد قاموس من نص إلى رقم_صحيح()
اجعل النقاط = ١٠      زد النقاط بمقدار ١      انقص النقاط      اجعل الأسماء[٠] = "محمد"
إذا النقاط أكبر من ١٠ و حي { } وإلا إذا النقاط == ٣ { } وإلا { }
كرر ٥ مرات باستخدام ع { }      لكل اسم في الأسماء { }      لكل ع من ١ إلى ١٠ بخطوة ٢ { }      طالما شرط { }
حسب القيمة { حالة ١: ...   حالة ٢، ٣: ...   الباقي: ... }
حاول { } إن حدث خطأ خ { } أخيراً { }      ارمِ خطأ "رسالة"
بعد ٣ ثواني { }      كل ثانيتين { }      بعد ٢٠٠ ملي ثانية { }
مهمة اقفز(رقم_عشري قوة): منطقي { ارجع صح }
صنف عدو يرث شخصية ينفذ قابل_للكسر { عند_الانشاء(نص ا) { الأب(ا) } }      تعداد حالة_العدو: يتجول، يطارد      واجهة قابل_للكسر { مهمة انكسر() }
"النقاط: {النقاط}"            # قيمة المتغير داخل النص
(ع) ← ع > ٥                    # دالة قصيرة، مع: فلتر، جد، عد، لكل_عنصر
جافا { ... }                    # كود Java كما هو      استورد a.b.C باسم اسم
```

الأنواع: `رقم_صحيح int` `رقم_طويل long` `رقم_قصير short` `بايت byte` `رقم_عشري float` `عشري_دقيق double` `منطقي boolean` `حرف char`
`نص String` `كائن Object` `لا_ناتج void` · `قائمة ArrayList` `قائمة_مرتبطة LinkedList` `قاموس HashMap` `قاموس_مرتب TreeMap` `مجموعة HashSet`
`طابور / مكدس ArrayDeque` `مصفوفة من T = T[]` `قائمة_سريعة / قاموس_سريع` (libGDX Array / ObjectMap).

ملاحظات: `÷` قسمة حقيقية (`٥ ÷ ٢ = ٢٫٥`) و`/` قسمة Java · `٣٠٪ = ٠٫٣` · `==` بين نصين يقارن المحتوى · `حسب` بلا سقوط بين الحالات.

## الأحداث والعناصر

سكربت العنصر: `عند البدء` `كل إطار` `عند النقر` `عند بداية اللمس` `عند نهاية اللمس` `عند الاصطدام` `عند نهاية الاصطدام` (العنصر الآخر اسمه `الآخر`).
سكربت المشهد: `عند البدء` `كل إطار` `عند الإيقاف` `عند الاستئناف`. العنصر صاحب السكربت اسمه `نفسي`، وبقية العناصر تُكتب بأسمائها.

خصائص العنصر (بالبكسل، ص للأعلى، الزوايا بالدرجات)، قراءة وكتابة: `س اللاعب` أو `اللاعب.س`:
`س ص عرض ارتفاع دوران مرئي شفافية حجم سرعة_س سرعة_ص اسم نص لون صورة تقدم حي جسم`.

الجمل والدوال الجاهزة والأسماء العربية كلها في ملف واحد: `najma/src/main/resources/najma/lang.txt`. إضافة سطر فيه تضيف كلمة للغة.

## Java و libGDX

كل صنف وعضو يعمل باسمه الأصلي (`Gdx.input.isTouched()`، `جديد Vector2(1, 2)`). ولمعظمها أسماء عربية تُولَّد من قاموس الكلمات
(`setPosition` = `اجعل_الموضع`، `getWidth` = `العرض`، `isTouched` = `ملموس`): `الإدخال.ملموس()`، `متجه٢(١، ٢)`، `الراسم.دائرة(١٠٠، ١٠٠، ٥٠)`.
التغطية الحالية: 82% من أعضاء الأصناف الأساسية للألعاب، و58% من كل libGDX. ما ليس له اسم عربي يُكتب باسمه الإنجليزي.
كل مهام المشهد (StageImp) تُستدعى مباشرة: `toast("hi")`، `افتح_مشهد("menu")`.

## الأخطاء

أخطاء نجمة تظهر بالعربية مع رقم السطر واقتراح («هل تقصد...؟»). أخطاء مترجم Java على الملف المولَّد تُعرض على نفس السطر في ملف `.njm`
بعد ترجمة الشائع منها. أسطر أخطاء التشغيل (crash) تطابق أسطر ملف `.njm` لأن الملف المولَّد يحافظ على أرقام الأسطر.

## المحرر

`NajmaEditorActivity`: نص أندرويد أصلي (تشكيل الحروف والاتجاهين من النظام)، اتجاه كل سطر من أول حرف فيه (والسطر الذي لا حروف فيه مثل `}`
يتبع اليمين)، تلوين، أخطاء فورية، شريط رموز، إزاحة تلقائية، تراجع / إعادة، وزر يعرض كود Java الناتج.

الإكمال التلقائي فقاعة عند المؤشر تعتمد على ما كُتب قبله في السطر (`Najma.completeAt`): الأعضاء بعد النقطة، الكلمة التالية في الجملة
(«حرك نفسي» ← يميناً، يساراً، نحو...)، كلمات المقارنة بعد قيمة، الأسماء والدوال حيث تُنتظر قيمة، والأحداث في أول الملف.

زر «؟ الشرح» يفتح `NajmaGuideActivity`: شرح كامل بالعربية من الصفر إلى الاحتراف في أقسام، وقسم أمثلة جاهزة، والأكواد في بطاقات
مع زر نسخ. النص في `app/src/main/assets/najma/guide.md`، وكل كود فيه يُترجم ويُبنى ضمن الاختبارات فلا يبقى فيه مثال خاطئ.

(نسخة من `app/src/main/assets/java/game.zip`). كل حالة في `najma/src/test/cases/` تُترجم ثم يُبنى ناتجها بـ javac ويُشغَّل بعضها.
